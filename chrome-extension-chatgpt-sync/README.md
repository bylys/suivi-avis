# 🧩 Extension Chrome — Auto-Sync Cookies ChatGPT

Extension privée permettant de synchroniser automatiquement vos cookies ChatGPT avec Supabase pour alimenter l'Agent GMB Tracker.

## 🛠️ Installation en 3 clics :

1. Ouvrez Chrome et allez sur `chrome://extensions/`
2. Activez le **Mode développeur** (interrupteur en haut à droite).
3. Cliquez sur **Charger l'extension non empaquetée** (Load unpacked) et sélectionnez le dossier `chrome-extension-chatgpt-sync`.

C'est tout ! Dès que vous naviguez sur ChatGPT, l'extension met à jour automatiquement les cookies en arrière-plan.
